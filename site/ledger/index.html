How we compared

Each brief ran three times in each condition in a fresh workspace, with a 480-second host limit and the same file tools. The on condition loaded the ordinary Jevstice extension at revision 13fb998. The agent decided how to use its feedback. We mixed the run order and kept unfinished artifacts. A missing file is a missing delivery, never a zero.

We froze each checklist before launch and scored the delivered artifacts independently of Jev. Visual panels show median-scoring deliveries in each condition, not necessarily from the same repeat. The paired counts above do match repeat numbers. Three repeats describe these briefs; they do not establish a general model ranking.

GLM used OpenRouter; Luna and Sol used OpenAI Codex. The initial GLM route rejected an expired credential before inference. We ran all 18 GLM trials on the verified route and excluded the authentication failures and availability probes from this comparison.
